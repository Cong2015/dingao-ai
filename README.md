# 定稿AI · 研究生论文AI辅助系统（开发版 v0.4 · 本地优先架构）

> 写论文，用谁家都行；交稿之前，先定稿。

定稿AI 是面向研究生的论文写作全流程辅助系统。**v0.4 对应《R8 定稿AI-产品待办事项列表与完工定义(DoD)-V1.3》的全部 7 项 Must have**：辅助选择题目（M9）、辅助生成大纲（M10）、论文本地编写与 Word 备份（M11）、写作进度与打卡（M12）、中英文文献互译（M4）、交稿检查报告（M8）、工程地基与测试资产。

**v0.4 架构修订（本地优先）**：论文全文/大纲/进度/打卡**只存在用户自己的浏览器里（IndexedDB，按账号分库），服务器零存储**——即使服务器被攻破也拿不到任何论文内容。服务端仅保留：账号登录、AI 中转（输入内容仅内存转发给 DeepSeek、绝不落盘）、引用核查/交稿检查（只处理不存储）、工具结果记录（用户主动保存）。v0.2 的引用核查/分段校对/四要素/综述按 V1.3 降级保留（S7/S8/C7/C8），功能仍可用。

## 🚀 快速开始

双击 **`启动定稿AI.bat`**（推荐）——自动：①检测服务是否已在运行 ②添加防火墙放行规则（首次会弹 UAC，点"是"，仅需一次）③启动服务（异常退出 3 秒自动重启）④打开浏览器。

或手动：

```bash
npm install            # Node ≥ 22（node:sqlite 内置）
node server.js         # 密钥读取：环境变量 > config/key.txt > config/key.txt
```

- 本机访问：http://localhost:8788
- 局域网访问：**以服务窗口输出的地址为准**（登录页与侧边栏底部也会动态显示当前局域网地址——路由器 DHCP 换 IP 后自动更新）
- 首个注册账号自动成为管理员（可用平台 Key）；普通用户在「我的Key」配置自己的 DeepSeek Key（保存前本地核对，AES-256-GCM 加密落库，前端只显示掩码）

### 常见问题：网址打不开 / 其他电脑连不上

1. **服务没在运行**（最常见）：主机关机/窗口被关后服务即停止。解决：双击「启动定稿AI.bat」；可向产品组申请开机自启脚本（需你确认后安装）。
2. **防火墙拦截**（其他电脑连不上）：运行 bat 时会自动放行 TCP 8788；或手动以管理员执行：
   `netsh advfirewall firewall add rule name="dingao-ai-8788" dir=in action=allow protocol=TCP localport=8788`
3. **IP 变了**：局域网地址以登录页显示为准；建议在路由器把本机 MAC 绑定为固定 IP。
4. **登录态**：会话有效期 30 天，存于本机数据库，服务重启不清除。

## 🏗️ 技术栈

- **后端**：Node.js + Express + node:sqlite（零原生依赖）；SSE 事件协议；选题/大纲走非流式 JSON（response_format=json_object + 尽力解析）
- **AI**：DeepSeek API（deepseek-v4-flash 推荐 / v4-pro 易超时）；**不设 max_tokens**（V4 推理模型思考与答案共用输出预算，显式小值会饿死答案）
- **前端**：原生 HTML/CSS/JS（无构建步骤）；左侧分组导航（写作辅助/文献工具/交稿核查/我的）＋写作四视图＋工具工作区；响应式（≤1100px 侧栏收窄）
- **文档**：docx 库（导出）、adm-zip（docx 导入＋格式元数据）、pdf-parse（PDF 文本层）

## 🔒 合规红线（V1.4）

1. **内容0修改**：AI 只辅助不改写论断；校对「整篇一键修正」不提供，逐条确认后由用户应用（可撤销）；AI 结果标注需人工核验
2. **论文隐私（V1.4·本地优先）**：论文全文/大纲/进度/打卡仅存用户浏览器 IndexedDB（库名按账号隔离 `dingao_v04_<用户id>`）；服务端数据库只有 users/sessions/api_keys/records 四张表，没有任何论文数据表与存储端点；AI 调用输入仅内存中转不落盘
3. **数据最小化**：服务端仅存账号/会话/密钥/用户主动保存的工具结果记录
4. **密钥安全**：DeepSeek 密钥仅存服务端（AES-256-GCM）
5. **限流**：每用户 60 次 AI 请求/小时

> ⚠️ 本地存储提示：论文存在浏览器里，换电脑/换浏览器/清空浏览器数据将看不到（可随时导出 Word 备份）；Safari 隐私模式下 IndexedDB 受限，请使用普通模式。
