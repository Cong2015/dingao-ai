## 四、合规红线核对表

- [x] 内容0修改：校对/综述系统提示内建「不改动内容表述」约束；交稿检查只检不改
- [x] AI 输出标注：选题/大纲/互译等前端固定「AI生成，需人工核验」
- [x] **论文隐私（V1.3）**：论文全文仅存本机 SQLite；无任何云同步请求；每用户隔离（跨用户 404）；管理员无内容查看权（TC-100）
- [x] 数据最小化：记录仅存用户主动保存的结果，原文不落记录库
- [x] 密钥安全：仅服务端加载（环境变量 > API.txt > config/key.txt），AES-256-GCM 落库
- [x] 限流：每用户 60 次/小时 AI 请求
- [x] 引用核查/交稿检查/进度统计不走 LLM（规则引擎，零 AI 成本）
